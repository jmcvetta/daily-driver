The [Intelligence Index v5.0.2](https://artificialanalysis.ai/evaluations/artificial-analysis-intelligence-index) aggregates multiple evaluations. Terminal-Bench measures terminal-based agent work; FrontierCode measures software engineering in repositories. Compare the column closest to your workload rather than treating the overall index as a coding score.

Token rates are US dollars per million tokens before cache discounts. Cost per task is the weighted average for the Intelligence Index suite, not a price quote for your workload. Models can use different numbers of tokens on the same task, so equal token rates do not imply equal task costs.
